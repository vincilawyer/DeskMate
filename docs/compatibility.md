# 系统与手势兼容性

应用要求 macOS 14 或更高版本。当前本机构建和公开源码验收使用 Apple Silicon、macOS 26.6.2、Swift 6.1 与 macOS SDK 15.4；默认仅构建 arm64。

## 五指与二指触控

全局五指使用按 macOS 主版本、MultitouchSupport 框架版本与 CPU 限制的私有后备路径，另保留公开 AppKit 本地路径。未知、缺失或未验证的版本不启用私有解析，设置会提示使用快捷键或菜单栏。

代码中的允许组合包含 macOS 26、MultitouchSupport 9460.1、arm64。本机已完成对应接口与监听检查；9450.2 的既有允许组合保留，但没有扩大实机验收范围。

多块触控板独立保存手势状态，回调关闭、在途排空及迟到回调隔离均有检查。设备变化或唤醒时可重建监听。识别与延迟展示均检查本机光标可见性及显示器范围。

分页只接受精确二指横滑，三指以上、纵向动作和鼠标拖拽中的触点不分页。系统手势被观察而不被拦截。

内置和外接妙控触控板的五指功能已有实机反馈，但不代表所有设备型号、蓝牙重连与真实睡眠场景均已验收。双 Mac 指针交接后的五指仍需对应硬件实测。

## Dock 与跨屏边缘

Dock 预览使用辅助功能读取 Dock 图标和切换窗口，屏幕录制提供缩略图；权限只通过显式按钮请求，不请求输入监控。

跨屏边缘使用本机显示器几何和系统只读边缘接口。接口失败、空数据、停用或退出时清理提示；不调用通用控制管理接口，不改显示器排列，不接管键鼠。

登录后锁屏只允许边缘覆盖层，启动台、设置与窗口预览不会进入锁屏。FileVault 与重启后首次登录不受支持。

## 发布与系统升级

本地脚本使用临时签名。正式公开分发安装包需要 Developer ID 签名与 Apple 公证；私有触控路径不适合 Mac App Store。

系统升级后私有接口可能不可用，请依据实际设置中的兼容提示使用快捷键、菜单栏或手动边缘标记，不扩大未验证的版本允许范围。
